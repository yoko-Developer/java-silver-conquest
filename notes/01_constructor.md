## コンストラクタとは

インスタンス生成時に呼び出される特別なメソッド

自分自身のコンストラクタを呼び出す場合

一番上にコンストラクタ呼び出しを記述する


```
this(); // コンストラクタからコンストラクタを呼ぶ
```

引数がないものが指定されている

コンストラクタからコンストラクタを呼ぶ場合

- 呼ぶコンストラクタ：浅い
- 呼ばれるコンストラクタ：深い

### ⭐️コンストラクタは一番深いものから動く
### ⭐️ローカル変数とフィールド変数が同じ場合は **ローカル変数が優先**
### ⭐️コンストラクタは継承されない
### ⭐️`super` と `this` は併用できない


```
this.変数名 // フィールド変数
```
